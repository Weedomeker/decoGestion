Parcours d'un PDF de session Tauro : du job à la Queue de la Tauro

Lancement « en session » avec le dossier « Attente Tauro » renseigné dans la Config. Les PDF sont préparés en parallèle, mais arrivent dans le hot folder dans l'ordre d'impression : 001, 002, 003…

Cas particuliers

  • Échec puis réussite à la nouvelle tentative : le PDF garde sa place ; les suivants attendent dans le NAS, sans bloquer les jobs en préparation.
  • Échec définitif ou annulation : son numéro est sauté, la file continue.
  • Teinte masse : pas de PDF, hors de la file ; son numéro est vide dans le RIP, comme avant.
  • Déjà présent dans le hot folder : jamais écrasé, le PDF est sauté avec une erreur dans la File.
  • Hot folder injoignable : les PDF non envoyés restent sur le NAS. Bandeau dans la File, bouton Reprendre le dépôt une fois le hot folder revenu : envoi dans l'ordre. Ne pas relancer ces jobs (double impression).
  • Hors session et lancement classique : dépôt direct, comme avant.

Arrêt du serveur

  • Pendant la préparation : les jobs retirés au redémarrage voient leur PDF d'attente supprimé (jamais envoyé) ; ils sont à relancer.
  • Pendant les envois : les PDF restés dans l'attente du jour sont retrouvés au redémarrage et proposés avec Reprendre le dépôt (chaque PDF a sa fiche à côté de lui sur le NAS).

Réglage

  • Config → « Attente Tauro » : \\NASSYNORS1221\temp.
  • Champ vide : fonction désactivée, dépôt direct comme avant.
